# Interconexiones del sistema

Sitio estático e interactivo para explorar las relaciones entre sectores.

## Uso

Abrí `index.html` con un navegador moderno. No requiere instalación, servidor,
backend ni proceso de compilación.

## Estructura

- `js/departments.js`: sectores, colores y posiciones.
- `js/resources.js`: catálogo único de recursos.
- `js/flows.js`: fuente canónica de las relaciones y sus recorridos.
- `js/app.js`: validación, interacción y representación.
- `css/styles.css`: diseño, estados visuales y adaptación de pantalla.
