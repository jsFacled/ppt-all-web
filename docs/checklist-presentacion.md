# Checklist de presentación

## Antes de salir

- [ ] Copiar la carpeta completa del proyecto.
- [ ] Confirmar que `index.html` abre con doble clic y muestra el índice.
- [ ] Confirmar que `#/interconexiones` abre el mapa.
- [ ] Verificar que el navegador funcione sin conexión.
- [ ] Llevar una copia de respaldo en otra ubicación.

## Navegación del motor

- [ ] Abrir Interconexiones desde el índice.
- [ ] Presionar `M` para abrir el índice desde el mapa.
- [ ] Presionar nuevamente `M` o `Esc` para regresar al mapa.
- [ ] Confirmar que el contador principal muestre `1 / 1`.
- [ ] Confirmar que los pasos aparezcan en un indicador separado del contador.
- [ ] Usar `AvPág` para recorrer vista inicial, Dirección y Tecnología.
- [ ] Usar `RePág` para volver de Tecnología a Dirección y a la vista inicial.
- [ ] Seleccionar libremente otro sector y confirmar que el indicador de paso
      no cambie.
- [ ] Activar el modo presentación con el botón y con `P`.
- [ ] Presionar `Esc` para salir del modo presentación.

## Interconexiones

- [ ] Comprobar la vista inicial sin flechas.
- [ ] Revisar Dirección y Directorio.
- [ ] Revisar Tecnología / IT / Data.
- [ ] Revisar al menos un sector lateral y Back Office.
- [ ] Confirmar que ninguna flecha atraviese un sector.
- [ ] Confirmar que las etiquetas principales sean legibles y no se pisen.
- [ ] Verificar que el sector seleccionado muestre el pulso en el borde.
- [ ] Probar `Todas`, `Recibe` y `Entrega`.
- [ ] Confirmar que el filtro persista al cambiar de sector.
- [ ] Presionar `←` y `→` para recorrer sectores sin cambiar de diapositiva.
- [ ] Presionar `Enter` para seleccionar el sector enfocado.
- [ ] Abrir y cerrar el panel informativo.
- [ ] Restablecer el mapa con el control visible.

## Verificación técnica

- [ ] Montar y desmontar Interconexiones diez veces sin respuestas duplicadas.
- [ ] Confirmar que el índice sigue operativo después de los diez ciclos.
- [ ] Confirmar que una entrada inválida aparece marcada en el índice y muestra
      un error contenido en su ruta.
- [ ] Confirmar que no se realizaron solicitudes de red.

## En la sala

- [ ] Conectar el proyector y usar su resolución definitiva.
- [ ] Mantener el zoom del navegador en 100 %.
- [ ] Recorrer el índice, los tres pasos y la interacción libre.

## Justo antes de presentar

- [ ] Abrir `index.html` y dejar la vista inicial preparada.
- [ ] Cerrar pestañas y aplicaciones innecesarias.
- [ ] Desactivar notificaciones.
- [ ] Evitar que el equipo entre en suspensión.
